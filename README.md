# Системы поддержки принятия решений

В ноутбуке [`SPPR_tasks_2_1-2_10.ipynb`](SPPR_tasks_2_1-2_10.ipynb) выполнены упражнения **2.1–2.10** из пособия  «Системы и методы поддержки принятия решений» (СПбГЭТУ «ЛЭТИ», 2026), с. 93–97.

Каждая задача содержит условие, исходные данные, математическую модель, исполняемый код Pyomo и ответ. Включены явная двойственная задача, линеаризация абсолютных величин, минимаксная модель, преобразование Charnes–Cooper и графическое решение задачи 2.9. Результаты выполнения сохранены в ноутбуке.

В задаче 2.2 учтены уточнённые нормы древесины: **5 досковых футов на стул и 15 на стол**. Задача 2.8 представлена параметрически: численные значения времени в пути, дедлайнов и ставок штрафа в условии не заданы.
